Sodium 区块渲染系统

多线程异步构建与批处理渲染机制

1. 概述

区块（Chunk）是 Minecraft 世界的基本渲染单位。Sodium 通过多线程异步构建和批处理渲染显著优化了区块渲染性能。

8. 性能优化要点

优化项实现方式效果
多线程构建专用工作线程池帧率更稳定
直方图排序O(n) 排序算法排序更快
MultiDraw批量绘制减少 Draw Calls
