第37章 命令系统入门 —— 理解 Minecraft 的指令世界

目标

  • 理解命令（Command）是什么

  • 了解命令上下文（CommandContext）

核心概念

什么是命令？

命令（Command） 是玩家或系统向游戏发送的指令。

想象你去餐厅点菜：

  • 你 = 命令发送者（谁下的命令）
  • 服务员 = 命令系统（接收和处理命令）
  • 菜单 = 已知命令列表
  • 厨师 = 命令执行者（真正做事的人）

在 Minecraft 中，当你输入 /give @p diamond 64 时：

/give @p diamond 64
│    │    │      │
│    │    │      └─ 数量：64个
│    │    └─ 物品：钻石
│    └─ 目标：最近的玩家
└─ 命令名：give（给物品）

命令源（CommandSource）

命令源 是"谁下的命令"，它包含了执行命令所需的所有信息。

classDiagram class CommandSource { <> +getPlayerNames() 玩家列表 +getPosition() 位置 +getWorld() 世界 +hasPermissionLevel(int) 权限检查 +sendMessage(Text) 发送消息 } class ServerCommandSource { +Vec3d position 坐标 +ServerWorld world 世界 +int level 权限等级 +String name 名称 +Text displayName 显示名 +Entity entity 执行实体 +MinecraftServer server 服务器 } CommandSource <|-- ServerCommandSource

命令上下文（CommandContext）

命令上下文 就像是你点菜后服务员给你的"小票"——包含了这次命令的所有信息。

classDiagram class CommandContext~S~ { +S source 命令源 +String input 原始输入 +Map~String, Argument~ arguments 参数 +getArgument(name) 获取参数 +getSource() 获取命令源 } class ServerCommandSource { +Vec3d position +ServerWorld world +MinecraftServer server } CommandContext "1" o-- "1" ServerCommandSource

命令解析流程

当你输入一个命令，Minecraft 内部是这样处理的：

sequenceDiagram participant 玩家 participant 命令系统 participant Brigadier解析器 participant 命令执行器 玩家->>命令系统: 输入 "/give Steve diamond 64" 命令系统->>Brigadier解析器: 发送命令字符串 Brigadier解析器->>Brigadier解析器: 1. 解析命令结构 Brigadier解析器->>Brigadier解析器: 2. 验证参数类型 Brigadier解析器->>Brigadier解析器: 3. 检查权限 Brigadier解析器-->>命令执行器: 返回 CommandContext 命令执行器->>命令执行器: 4. 执行具体逻辑 命令执行器-->>玩家: 5. 返回结果/消息

核心代码

ServerCommandSource 的核心字段

public class ServerCommandSource implements CommandSource {
    
    // 命令输出目标（发送消息用）
    private final CommandOutput output;
    
    // 位置（命令执行的地方）
    private final Vec3d position;
    
    // 世界（命令在哪个世界执行）
    private final ServerWorld world;
    
    // 权限等级（0=普通玩家, 4=管理员）
    private final int level;
    
    // 执行者的名字和显示名
    private final String name;
    private final Text displayName;
    
    // 服务器引用
    private final MinecraftServer server;
    
    // 如果是玩家/实体执行的，保存这个实体
    private final Entity entity;
    
    // 视角旋转
    private final Vec2f rotation;
}

命令调度的核心代码

public class CommandManager {
    private final CommandDispatcher<ServerCommandSource> dispatcher = new CommandDispatcher();
    
    // 执行命令（带 / 前缀）
    public void executeWithPrefix(ServerCommandSource source, String command) {
        command = command.startsWith("/") ? command.substring(1) : command;
        this.execute(this.dispatcher.parse(command, source), command);
    }
    
    // 执行命令
    public void execute(ParseResults<ServerCommandSource> parseResults, String command) {
        ServerCommandSource source = parseResults.getContext().getSource();
        // 解析命令
        ContextChain<ServerCommandSource> contextChain = 
            CommandManager.checkCommand(parseResults, command, source);
        
        if (contextChain != null) {
            // 执行命令
            CommandExecutionContext.enqueueCommand(context, command, contextChain, source, ...);
        }
    }
}

从上下文获取数据

public class CommandExample {
    
    public static int execute(ServerCommandSource source, CommandContext<?> context) {
        // 获取命令源
        ServerCommandSource src = context.getSource();
        
        // 获取玩家（如果存在）
        if (src.getEntity() instanceof ServerPlayerEntity player) {
            player.sendMessage(Text.literal("你执行了命令！"));
        }
        
        // 获取坐标
        Vec3d pos = src.getPosition();
        
        // 获取世界
        ServerWorld world = src.getWorld();
        
        // 发送反馈
        source.sendFeedback(() -> Text.literal("命令执行成功！"), broadcastToOps);
        
        return 1; // 返回成功
    }
}

小结

  • 命令（Command） 是玩家向游戏发送的指令，如 /give、/tp、/time

  • 命令源（CommandSource） 代表"谁下的命令"，包含：
- 执行者的位置、所在世界 - 权限等级 - 服务器引用 - 可以发送消息给执行者

  • 命令上下文（CommandContext） 包含一次命令执行的所有信息：
- 命令源 - 解析后的参数

  • 命令解析流程：
   玩家输入 → 字符串解析 → 参数验证 → 权限检查 → 执行 → 反馈

  • Brigadier 是命令解析库，它将命令字符串解析成结构化的 CommandContext
