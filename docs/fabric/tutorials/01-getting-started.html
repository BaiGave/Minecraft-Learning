什么是 Fabric？

Fabric 是一个轻量级的 Minecraft 模组加载器，与 Forge 相比，它以高性能和快速更新著称。

环境搭建

前置要求

- JDK 17+

- Gradle 8.x

- Minecraft 1.20+

创建项目

fabric create --id com.example:fabric-mod
cd fabric-mod
./gradlew build

添加依赖

在 build.gradle 中添加 Fabric API：

dependencies {
    modImplementation "net.fabricmc:fabric-loader:${project.loader_version}"
    modImplementation "net.fabricmc.fabric-api:fabric-api:${project.fabric_version}"
}

入口类

@Mod(ExampleMod.MOD_ID)
public class ExampleMod {
    public static final String MOD_ID = "fabric-mod";

    public ExampleMod(FabricBundleContext ctx) {
        LOGGER.info("Fabric mod loaded!");
    }
}
