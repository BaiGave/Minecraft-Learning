Mixin 是什么？

Mixin 是一个 Java 注解处理器框架，允许你在不修改原类的情况下，向现有类注入代码。

基本配置

添加依赖

implementation "org.spongepowered:mixin:0.8.5"

配置 mixins

在 fabric.mod.json 中注册：

"mixins": [
  "modid.mixins.json"
]

创建 src/main/resources/modid.mixins.json：

{
  "required": true,
  "package": "com.example.mixins",
  "compatibilityLevel": "JAVA_17",
  "mixins": [],
  "client": ["ClientMixin"],
  "injectors": { "defaultRequire": 1 }
}

编写 Mixin

@Mixin(Player.class)
public abstract class PlayerMixin {

    @Inject(at = @At("HEAD"), method = "tick")
    private void onTick(CallbackInfo ci) {
        System.out.println("Player is ticking!");
    }
}

常见注解

注解作用
------------
`@Inject`在指定位置注入代码
`@Overwrite`完全覆盖原方法
`@Redirect`重定向方法调用
`@ModifyArg`修改方法参数
