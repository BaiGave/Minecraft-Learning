关键类

FabricLoader

主加载器，负责扫描 mods 目录、解析 fabric.mod.json：

public class FabricLoader {
    public static FabricLoader instance;

    public void initialize() {
        // 1. 扫描所有 mod JAR
        // 2. 解析 fabric.mod.json
        // 3. 按依赖顺序加载
        // 4. 调用 entrypoint
    }
}

Entrypoint 机制

{
  "entrypoints": {
    "main": ["com.example.ModInitializer"],
    "client": ["com.example.ClientInitializer"],
    "fabric": ["com.example.FabricModInitializer"]
  }
}

Mixin 注入时机

Mixin 在游戏初始化早期注入，此时游戏类已加载但尚未执行初始化逻辑：

1. PreLaunch → Mixin 配置加载

2. SettingUp → Mixin 环境初始化

3. BeforeCoreSetup → Mixin 处理器创建

4. Loading → 真正的注入发生

与 Forge 的区别

特性FabricForge
---------------------
