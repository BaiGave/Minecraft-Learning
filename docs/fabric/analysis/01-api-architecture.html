概述

Fabric API 是 Fabric 模组开发的核心依赖库，提供了大量与 Minecraft 交互的接口。

模块结构

fabric-api/
├── fabric-api-base/       # 基础接口与工具
├── fabric-block-api/      # 方块相关 API
├── fabric-item-api/       # 物品相关 API
├── fabric-entity-api/    # 实体相关 API
├── fabric-networking/     # 网络通信 API
└── fabric-rendering/     # 渲染相关 API

核心机制：Registry Entry

Fabric 使用 RegistryEntry 来管理游戏对象，与原版 Registry 类似但更灵活：

// 注册自定义方块
Registry.register(Registries.BLOCK, new Identifier("modid", "custom_block"), CUSTOM_BLOCK);

// 通过 API 获取
Block block = FabricBlockApi.getRegistry().get(new Identifier("modid", "custom_block"));

事件系统

Fabric 使用回调式事件系统：

// 监听玩家加入事件
PlayerJoinEventsCallback.EVENT.register((server, player) -> {
    server.getPlayerManager().broadcast(
        Text.literal(player.getName().getString() + " 加入了游戏！")
    );
    return PlayerJoinEventsCallback.StartReturnValue.CONTINUE;
});
