第36章 同步机制详解

目标

  • 理解 Minecraft 中的数据同步概念
  • 掌握玩家位置同步的实现方式
  • 了解区块（Chunk）同步机制

  • 完成 第34章 数据包系统

  • 了解 Minecraft 世界和实体的基本概念

核心概念

什么是同步？

同步 = 让所有玩家看到相同的游戏世界 就像视频会议：
  • 每个人都看到相同的画面
  • 一个人的操作，其他人也能看到
  • 如果不同步，就会出现"你看到我在A点，但实际上我在B点"的情况

Minecraft 同步的三个层次

| 层次 | 同步内容 | 重要性 | |------|----------|--------| | 位置同步 | 玩家、实体在哪里 | 最高 | | 区块同步 | 玩家周围的方块数据 | 高 | | 实体同步 | 实体的状态、属性 | 中 |

实战演示

场景：玩家移动和同步

1. 客户端本地处理（预测）： 

// 这样玩家感觉操作是"即时"的
public void onPlayerInput(PlayerInputPacket packet) {
    // 立即更新本地玩家位置
    Vec3d newPos = calculateNewPosition(localPlayer, packet);
    localPlayer.setPosition(newPos);
    localPlayer.setVelocity(input);

    // 同时发送给服务端
    connection.send(new PlayerMoveC2SPacket(newPos.x, newPos.y, newPos.z, ...));
}
2. 服务端验证： 

public void onPlayerMove(PlayerMoveC2SPacket packet) {
    // 检查移动是否合法
    if (isMoveValid(player, packet)) {
        // 合法：更新位置并广播
        player.setPosition(packet.getPos());
        broadcastToNearby(packet);  // 通知周围玩家
    } else {
        // 非法：回滚位置
        player.setPosition(player.getPreviousPos());
        // 发送校正包
        connection.send(new PlayerPositionLookS2CPacket(
            player.getX(), player.getY(), player.getZ(),
            player.getYaw(), player.getPitch()
        ));
    }
}

小结

  • 同步 = 让所有玩家看到相同的游戏世界
  • 客户端预测 = 客户端先本地处理，让操作感觉即时
  • 服务端权威 = 服务端是"真理之源"，可以纠正客户端
  • 三种同步：
- 位置同步：玩家和实体的位置 - 区块同步：玩家周围的方块数据 - 实体同步：实体的状态和属性
  • 数据包驱动 = 所有同步都通过数据包实现

练习

  • 在源码中查找 PlayerPositionLookS2CPacket，理解它如何纠正客户端位置

  • 思考：为什么服务端要有"权威"？如果客户端可以随意移动会怎样？
