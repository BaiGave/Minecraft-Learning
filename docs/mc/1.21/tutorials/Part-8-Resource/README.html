资源包 vs 数据包

特性资源包 (Resource Pack)数据包 (Datapack)
-----------------------------------------------
**位置**`.minecraft/resourcepacks/`世界文件夹的 `datapacks/`
**内容**材质、音效、模型配方、战利品、进度
**生效范围**客户端服务端（影响所有玩家）
**修改对象**视觉表现游戏逻辑
**可动态切换**是需要 /reload

关键类对照表

Minecraft 1.21说明用途
-----------------------------
`Identifier`资源定位符唯一标识资源：`minecraft:stone`
`ResourcePack`资源包接口提供资源文件的读取
`ResourceManager`资源管理器协调所有资源包，提供统一访问
`LootTable`战利品表定义掉落物规则
`LootPool`战利品池一次掉落抽奖
`Advancement`进度定义成就和任务
`Recipe`配方接口定义合成规则
`RecipeManager`配方管理器管理所有配方
