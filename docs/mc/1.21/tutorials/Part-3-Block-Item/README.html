核心概念概览

方块（Block）

┌─────────────────────────────────────────────┐
│                                             │
│  Block (方块类)                              │
│    │                                        │
│    ├── 定义方块的通用属性                      │
│    │   ├── 硬度、爆炸抗性                    │
│    │   ├── 音效、碰撞箱                      │
│    │   └── 随机刻更新                        │
│    │                                        │
│    └── BlockState (方块状态)                 │
│          │                                  │
│          ├── 存储方块的"样子"                │
│          ├── 可以改变（旋转、开关等）          │
│          │                                  │
│          └── BlockEntity (方块实体)          │
│                │                            │
│                ├── 存储额外数据               │
│                ├── 每个位置独立               │
│                └── 用于箱子、熔炉等            │
│                                             │
└─────────────────────────────────────────────┘

物品（Item）

┌─────────────────────────────────────────────┐
│                                             │
│  Item (物品类)                              │
│    │                                        │
│    ├── 定义物品的行为                        │
│    │   ├── 使用、攻击、放置                  │
│    │   ├── 食物效果                         │
│    │   └── 工具加成                         │
│    │                                        │
│    └── ItemStack (物品堆)                   │
│          │                                  │
│          ├── 物品类型 + 数量                 │
│          ├── 组件数据（1.21新）              │
│          │   ├── 附魔                        │
│          │   ├── 自定义名称                  │
│          │   └── 耐久度                      │
│          │                                  │
│          └── 可以操作（拆分、合并、复制）     │
│                                             │
└─────────────────────────────────────────────┘
