面向零基础开发者的 Minecraft 源码完全指南

教程概览

本教程旨在帮助完全不懂 Minecraft 源码的人，通过这套课程：

1. 理解 Minecraft 的架构设计

2. 掌握 核心系统的实现原理

3. 能够 进行 Mod 开发

每章节学习方法

1. 先看图 - Mermaid 图是理解概念的最佳方式

2. 再看文字 - 带着图的理解去读文字

3. 然后看代码 - 代码是概念的具体实现

4. 最后做练习 - 巩固所学知识
