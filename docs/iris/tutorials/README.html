教程信息

模组：Iris 光影

类型：教程

从零开始学习 Iris 着色器开发

教程概览

本教程系列将带你从零开始学习 Iris 光影 Mod 开发，包括：

1. Shader 基础入门 - GLSL 语法与着色器核心概念

2. 开发环境搭建 - 配置 Iris 开发环境

3. 创建第一个 Shader - 编写简单的 GLSL 着色器

4. ShaderPack 结构 - 理解光影包的文件结构

5. Uniform 实践 - 使用内置 Uniform

6. 后处理效果 - 实现各种视觉效果

前置要求

- 熟悉 Java 编程

- 了解 Minecraft Mod 开发基础

- 对图形渲染有基本了解（可选）

学习路径

建议按顺序学习本教程系列：

顺序教程难度预计时间
----------------------------
1Shader 基础入门入门60分钟
2Iris 开发环境搭建入门45分钟
3创建第一个 Shader基础90分钟
4ShaderPack 结构基础60分钟
5Uniform 实践中级75分钟
6后处理效果高级120分钟
