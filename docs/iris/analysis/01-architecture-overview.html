3. 关键设计模式

3.1 观察者模式

FrameUpdateNotifier 用于通知 Uniform 更新：

    private final Set<Runnable> listeners = new HashSet<>();
    
    public void onNewFrame() {
        for (Runnable listener : listeners) {
            listener.run();
        }
    }
    
    public void addListener(Runnable listener) {
        listeners.add(listener);
    }
}
