核心优化技术

技术说明效果
------------------
**高级视锥体剔除**基于光源方向的智能剔除阴影渲染加速
**GBuffer 多目标**延迟渲染架构高质量后期处理
**Uniform 缓存**脏值检测优化减少 GPU 传输
**深度复制优化**智能选择复制策略减少带宽占用
**Buffer 翻转**主/备用纹理切换支持 Ping-Pong 渲染
**计算着色器**异步后处理性能提升

OpenGL 要求

要求版本说明
------------------
**最低版本**OpenGL 3.3基本功能
**推荐版本**OpenGL 4.5全部功能
**可选扩展**GL_ARB_shader_storage_buffer_objectSSBO 支持
**可选扩展**GL_ARB_compute_shader计算着色器
