🎯 什么是 Shader？

Shader（着色器）是运行在显卡上的特殊程序，可以创造出令人惊叹的视觉效果！

💬 常见问题

Q: 我需要会 Java 吗？ A: 不需要！Shader 使用的是 GLSL 语言。 Q: 我需要懂数学吗？ A: 基本的加减乘除就够了。我们会解释所有用到的数学。 Q: 电脑配置要求高吗？ A: 任何能运行 Minecraft 的电脑都可以开发 Shader。
