教程信息

模组：Sodium 优化

类型：教程

从零开始学习现代渲染优化技术

教程概览

本教程系列将带你学习渲染优化的核心技术，包括：

1. Mod 开发入门 - Fabric Mod 开发基础

2. 渲染优化基础 - 现代游戏渲染优化技术

3. 多线程编程 - 理解多线程与异步处理

4. 深入区块系统 - Minecraft 区块管理

5. OpenGL 基础 - GPU 渲染管线

6. 性能分析与调优 - 使用工具分析优化

前置要求

- 熟悉 Java 编程

- 了解 Minecraft 基本概念

- 具备高中数学基础（向量、矩阵）

学习路径

建议按顺序学习本教程系列：

顺序教程难度预计时间
----------------------------
1Mod 开发入门入门60分钟
2渲染优化基础入门90分钟
3多线程编程基础75分钟
4深入区块系统基础80分钟
5OpenGL 基础中级100分钟
6性能分析与调优高级90分钟
